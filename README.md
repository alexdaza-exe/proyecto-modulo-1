# Proyecto modulo 1
Este es el repositorio para el proyecto 1 de la clase de fundamentos de programacion, consta de 3 programas en pseudocodigo y su respectivo diagrama en mermaid

##**Problema 1**
Este denominado por mi problema numero 1 consta de un programa para nutrir la necesidad de calcular si un año es bisiesto o si no lo es, utiliza condiciones y operadores logicos para la condicion de si el numero es divisible entre 4 y 100 o entre 400
