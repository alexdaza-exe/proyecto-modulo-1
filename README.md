# Proyecto modulo 1
Este es el repositorio para el proyecto 1 de la clase de fundamentos de programacion, consta de 3 programas en pseudocodigo y su respectivo diagrama en mermaid

## **Problema 1** (problema-1)

Este denominado por mi problema numero 1 consta de un programa para nutrir la necesidad de calcular si un año es bisiesto o si no lo es, utiliza condiciones y operadores logicos para la condicion de si el numero es divisible entre 4 y 100 o entre 400

## **Problema 2** (problema-2)

El problema 2 es una plataforma para calcular el imc "(Indice de masa corporal)" y al mismo tiempo, indica en que categoría se encuentra, ya que aveces no basta solo con saber el imc por que es un dato muy ambiguo si no se tiene una referencia bajo que medirlo

## **Problema 3** (problema-3)

El programa 3 calcula el promedio de 5 calificaciones, es una estructura de acumulaciones y al final divide entre el numero de datos mismo, para entregar un promedio al usuario, añadi por mi parte una condicion para mostrar si el alumno aprobó o no
